Admin login

Connect to GitHub

One-time step for this browser. The admin panel saves your changes into the website's GitHub repository, and it needs an access token to do that.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories →
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate the token, copy it and paste it below.

The token is kept only in this browser, locked with your two passwords. It is never put on the website.
